# Operator Panel v0.5.2 Release Notes

**Release date:** 2026-09-23

A wording correction for the n8n exposure note in the Overview.

## The n8n note explains what the publish actually covers

The previous note read as if the agent connection depended on the host
publish ("Set `N8N_BIND_IP=127.0.0.1` to keep MCP inside the Docker network"),
which suggested that closing the port would break Hermes. The Hermes agent
reaches n8n over the internal Docker network, so the note now states what the
publication adds and what changing the bind affects:

```text
n8n publishes its editor and MCP endpoint to 192.168.4.222:5678. Hermes
reaches n8n over the internal Docker network, so this publication only adds
LAN access to the editor and MCP. Set N8N_BIND_IP=127.0.0.1 to keep the port
on loopback and publish the editor through the reverse proxy instead.
```

No behavior change: the warning still fires only while an n8n container is
running and the bind is beyond loopback.
