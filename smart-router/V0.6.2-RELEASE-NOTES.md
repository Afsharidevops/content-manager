# Hermes Smart Router v0.6.2 Release Notes

**Release date:** 2026-09-22

## Content production agents

The router now ships the four production roles that sit between research and
rendering. They are seeded into the control database on startup, appear on the
panel's Agents page, and join the orchestrator catalog, so a plan can assign a
step to them like any other agent.

| Agent | Responsibility |
| --- | --- |
| Storyboard Agent | Turn a topic, script, or research notes into scenes with hooks, pacing, and visual direction |
| Video Director Agent | Turn a script or storyboard into a render timeline document |
| Media Planning Agent | Choose the cheapest asset per scene and name one search query per asset |
| NotebookLM Recovery Agent | Read a recorded browser page state and return one recovery decision |

## Content endpoints

```text
GET  /v1/content/agents       list the seeded agents and their IDs
POST /v1/content/storyboard   {"topic"|"script", "platform", "duration", "language", "style"} -> storyboard JSON
POST /v1/content/timeline     {"script"|"storyboard", "aspect_ratio", "language"}            -> timeline JSON
POST /v1/content/video-plan   storyboard + timeline in one call
POST /v1/content/media-plan   {"scenes", "budget", "providers"}                              -> asset plan JSON
POST /v1/content/recover      {"step", "error", "page_state", "attempt"}                     -> recovery decision
```

Every answer is parsed and clamped by a deterministic normalizer before it is
returned, and a malformed answer gets one repair round trip. The timeline the
Video Director returns is the only input the Media Studio `timeline-video`
driver accepts, so a raw script never reaches the renderer. This closes the
Phase 2 pipeline: research -> script -> director -> timeline JSON ->
Media Studio -> MP4.

## Upgrade

```bash
cd /path/to/content-manager
git pull --ff-only
sed -i 's/^SMART_ROUTER_IMAGE_TAG=.*/SMART_ROUTER_IMAGE_TAG=0.6.2/' .env
docker compose pull smart-router
docker compose up -d smart-router
curl -sS "http://$(grep '^SMART_ROUTER_BIND_IP=' .env | cut -d= -f2-):$(grep '^SMART_ROUTER_PORT=' .env | cut -d= -f2-)/health"
curl -sS -H "Authorization: Bearer $SMART_ROUTER_ADMIN_API_KEY" \
  "http://$(grep '^SMART_ROUTER_BIND_IP=' .env | cut -d= -f2-):$(grep '^SMART_ROUTER_PORT=' .env | cut -d= -f2-)/v1/content/agents"
```
