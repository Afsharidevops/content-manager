# V0.6.4 — Video Studio Production Platform

## What's new

**Video Studio** — a new page in the Operations Center **Build** group that lets operators
create persisted production jobs and walk them through the full render pipeline:

**Storyboard → Timeline → Render → Download**

### Production job model (`v64_production_jobs`)

Persisted jobs with states: `draft → storyboard_created → timeline_ready → rendering → done / failed`.

| Field | Description |
|---|---|
| `title`, `topic`, `script` | Source content for the production |
| `platform`, `aspect_ratio` | Target platform (youtube, etc.) and render aspect ratio (`9:16` or `16:9`) |
| `language`, `style` | Narration language and visual style |
| `status` | Current lifecycle state (indexed) |
| `storyboard_json`, `timeline_json` | Structured JSON documents produced by the content agents |
| `ms_job_id`, `ms_artifact_name` | Media Studio render job reference |
| `actor`, `error` | Who created the job and the latest error (if any) |

### New control-plane endpoints

All scoped under `/control/api/production/`:

| Method | Path | Description |
|---|---|---|
| `POST` | `/jobs` | Create a production job |
| `GET` | `/jobs` | List jobs (optional `?status=` and `?limit=` filters) |
| `GET` | `/jobs/{id}` | Get a single job with full storyboard/timeline JSON |
| `DELETE` | `/jobs/{id}` | Delete a draft/complete job |
| `POST` | `/jobs/{id}/storyboard` | Invoke the Storyboard Agent |
| `POST` | `/jobs/{id}/timeline` | Invoke the Video Director Agent |
| `POST` | `/jobs/{id}/render` | Submit to Media Studio for ffmpeg rendering |
| `GET` | `/jobs/{id}/render` | Poll Media Studio render status |
| `GET` | `/jobs/{id}/artifact/{name}` | Download the rendered artifact |

### Operations Center changes

- **Video Studio** page (Build nav-group) with job creation form, job list with
  status badges, per-job action buttons (Storyboard → Timeline → Render → Download),
  and detail accordion showing storyboard scenes, timeline document, and render state.
- New **Video Studio** section in the built-in operator docs.

## Breaking changes

None. All existing endpoints and panel pages are unchanged.

## Configuration

Rendering requires the Media Studio URL to be set at startup:

- `SMART_ROUTER_MEDIA_STUDIO_URL` — base URL of the Media Studio instance
- `SMART_ROUTER_MEDIA_STUDIO_TOKEN` — bearer token for Media Studio auth (optional)

## Upgrade notes

1. Pull the new image:
   ```bash
   sed -i 's/^SMART_ROUTER_IMAGE_TAG=.*/SMART_ROUTER_IMAGE_TAG=0.6.4/' .env
   docker compose --profile smart-router pull smart-router
   docker compose --profile smart-router up -d smart-router
   ```
2. The new `v64_production_jobs` table is created automatically by SQLAlchemy on first start.
3. Existing 0.6.3 containers continue running; there is no schema migration needed for existing data.
