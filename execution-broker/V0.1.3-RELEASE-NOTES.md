# Hermes Execution Broker v0.1.3 Release Notes

Companion execution-boundary release for Hermes Linux Stack v0.5.8.

## Changes

- Execution Admin status reports version `0.1.3`.
- Browser CORS preflight can return `Access-Control-Allow-Private-Network: true` only when the exact request origin is already allowed.
- Works with the new host helper `./manage.sh configure-execution-admin-browser ORIGIN [PRIVATE_IPV4]`.
- No trust-boundary expansion: admin mode still does not receive the Ed25519 signing private key, Docker socket, SSH private credentials, or Smart Router admin credential.

For production, publish both AMD64/ARM64 manifests, verify them, and prefer an immutable digest for this security boundary.
